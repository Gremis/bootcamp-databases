# Bootcamp Databases

SQL and MongoDB exercises developed during the Orion bootcamp.

## Exercises

The database exercises will be organized under banco-de-dados/, with one directory per exercise.

- Exercise 1: Relational schema, primary keys, foreign keys, and inserts.
- Exercise 2: Joins, filters, and updates.
- Exercise 3: MongoDB documents and flexible schemas.
- Exercise 4: MongoDB queries and independent Docker development and production environments.

## Workflow

Feature branches start from develop and are integrated through reviewed pull requests.
Changes are promoted from develop to production through a separate reviewed pull request.

The production branch is the final delivery branch.
Commit messages follow Conventional Commits.

## Local configuration

Local .env files must not be committed.
Environment examples use fictitious values.
